# JSON Lens

一个可直接加载的 Chrome 扩展，用于查看、编辑和格式化 JSON，并通过你配置的 OpenAI 兼容接口从选中文字中提取 JSON。

## 安装

需要 Chrome 120 或更新版本。

1. 打开 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择此项目的 **`extension` 目录**。
4. 将 JSON Lens 固定到工具栏，点击图标打开编辑器。

无需构建即可安装，也可以运行 `npm run build` 后加载 `dist` 目录。更新源代码后，在扩展管理页点击「重新加载」；已打开的网页需要刷新。

## 使用

### 查看 JSON 网页

访问返回 `application/json`、`application/*+json` 或 `text/json` 的文档时，扩展会读取页面现有的原文，原地显示编辑器；不会再次请求接口。点击右下角「查看原始页面」可以恢复原文。

普通 HTML 页面不会被改写。要使用本地 `.json` 文件，请先在扩展详情中开启「允许访问文件网址」。Chrome 内部页面、商店页面等受浏览器限制的页面不支持注入。

### 右键处理文字

在网页中选中文字后，右键选择：

- **格式化 JSON**：在独立标签页中打开并格式化标准 JSON，不调用模型。
- **AI 提取 JSON**：只将本次选中的文字发送到已配置接口，识别其中的完整 JSON 对象或数组，在新标签页逐个查看。

首次使用 AI 前需要完成接口设置。若尚未配置，选中文字会保留在编辑器中，配置后点击「AI 提取 JSON」即可重试。

### 手动编辑

点击扩展图标，粘贴 JSON、接口响应或日志。左侧是可编辑源码，右侧是结构树。

- 格式化、压缩、复制格式化 JSON、下载 `.json`。
- 展开／折叠结构，按字段名或值搜索，点击节点后复制 JSONPath。
- 编辑有效 JSON 后自动更新结构。无效输入显示行列位置，右侧上次有效结构会变淡，并暂停复制和下载。
- AI 返回多个对象或数组时，通过下拉列表切换；「查看原始文本」可以回看本次输入。
- `⌘/Ctrl + Enter` 格式化，`⌘/Ctrl + K` 搜索，`Esc` 取消进行中的 AI 请求。
- 中文界面，自动跟随系统明暗主题。

## 接口配置

在编辑器右上角打开「接口设置」：

| 配置 | 示例或说明 |
| --- | --- |
| Base URL | `https://your-provider.example/v1`，或完整的 `/chat/completions` 地址 |
| API Key | 服务商提供的密钥；无需鉴权的本地兼容服务可留空 |
| 模型名称 | 服务商支持的模型 ID |

保存时按需申请接口域名访问权限。也支持 HTTP 本地／内网兼容接口。普通格式化不需要配置接口。

「测试连接」会发送 `{"connection":"ok"}` 作为示例输入，验证服务可用和返回格式，可能产生少量调用费用。实现使用非流式 `POST /chat/completions`，发送 `model`、`messages` 和 `stream: false`，不依赖服务商特有的 JSON Mode。需要模型遵守提取指令并返回 JSON 字符串列表。

## 数据保真与边界

格式化只改变 JSON 字符串以外的空白。不会通过 JavaScript 数字重新序列化数据，因此保留：

- `9007199254740993` 等大整数，以及 `1e400`、`-0` 等数字字面量。
- 原始字段顺序，包括数字形态的对象键。
- 重复字段及其顺序。重复字段会提示，其 JSONPath 可能相同。
- 字符串转义形式，例如 `"\u4e2d"`。

AI 结果经过本地校验，最终展示的内容来自原文。支持日志、代码围栏、JSON 字符串包裹的 JSON，以及可确定还原的裸转义片段。会保留原文中识别到的所有完整最外层对象／数组，包括重复出现的相同对象。模型改写数值、删字段、补全缺失内容等无法与原文对应的输出会被拒绝。

首版处理严格 JSON，不修复 JSON5、单引号对象、注释、末尾逗号或截断内容。无法闭合的外层结构会保守地阻止从其中提取局部子对象；不猜测不完整日志的边界。

| 范围 | 限制 |
| --- | --- |
| 本地输入 | 5 MiB，按 UTF-8 字节计算 |
| AI 输入 | 100 KiB，按 UTF-8 字节计算；超限不发送 |
| 嵌套结构 | 最多 256 层 |
| 转义解码 | 最多 3 层 |
| AI 超时 | 3 分钟（180 秒），支持主动取消，无自动重试 |
| 大型结构树 | 每批呈现 200 行，可继续加载，避免一次创建海量 DOM |
| 格式化膨胀 | 在过大缩进输出产生前停止；可改用压缩或缩小输入 |

## 存储与权限

- Base URL、API Key、模型名称仅保存在本机 `chrome.storage.local`，不进行云同步。API Key 未加密保存；不应把扩展存储视作密码保险箱。
- 本地配置限制为可信扩展上下文访问，网页脚本和内容脚本不能读取密钥。
- 原文、提取结果和编辑内容不保存历史；刷新或关闭编辑器后需要重新输入。右键传递的内容仅在内存中临时保留，读取后立即移除，最迟一分钟失效。
- 没有遥测、统计上报或中间代理服务。只有明确触发 AI 的操作会将输入发送到配置的接口；测试连接发送固定示例。
- 自动识别 JSON 页面需要允许扩展在网站上运行。内容脚本只处理 JSON MIME 文档；接口域名访问权限按需申请。

## 开发与验证

运行时没有第三方依赖，不加载 CDN 或远程脚本。扩展采用 Manifest V3 和本地 ES modules。Node.js 20.11+ 用于测试和构建。

```sh
npm ci
npm test
npm run build
```

端到端测试使用独立 Chromium 配置和本机 HTTP 服务，不使用真实密钥或外部 LLM：

```sh
npx playwright install chromium
npm run test:browser
```

如果已有 Playwright Chromium，可通过 `CHROMIUM_PATH` 指定可执行文件；设置 `HEADED=1` 可显示测试浏览器。浏览器测试覆盖真实扩展加载、JSON 页面增强、右键处理函数的内容传递、编辑／搜索／下载、模拟兼容接口、多结果、错误与取消。测试使用临时扩展副本并预授权本机模拟接口，不修改发布目录的权限；系统原生右键菜单点击及网站授权弹窗可按上方使用步骤手动复核。

测试截图输出到忽略版本控制的 `artifacts/`。真实服务商连通性需在扩展设置中使用你自己的接口配置完成验证。

```
extension/
  core/             严格 JSON 解析、转义提取、接口协议
  background.js     右键菜单、标签页和临时内容传递
  content.js        JSON 文档增强与原始页面恢复
  worker.js         后台解析与格式化
  viewer.*          编辑器页面与交互
  tree.js           结构树、搜索与路径
  options.*         本地接口设置
  style.css         明暗主题和布局
scripts/            构建与图标生成
tests/              单元测试和 Chromium 端到端测试
```
